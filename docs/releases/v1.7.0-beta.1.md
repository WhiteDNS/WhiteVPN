# WhiteVPN 1.7.0-beta.1

Experimental release: install only if you want to test the new connection engines.

- One Profiles page for built-in subscriptions, imported sources and saved engine profiles.
- Standalone SSH, Psiphon, Tor, DNS tunnels, IKEv2 and AmneziaWG; manual engine selection.
- Psiphon exit-country dropdown with localized names and Automatic.
- AmneziaWG configuration-file and vpn:// import.
- Consistent English/Persian forms and corrected password visibility-icon spacing.
- Existing Mihomo subscriptions, routing, chains and automatic selection retained.

Built on current 1.6.10 with its patched Mihomo core, connection-health checks,
update downloads and widget support retained. OpenConnect is retired.

SSH, DNS tunnels, AmneziaWG and IKEv2 require your compatible server/configuration.
SOCKS engines carry TCP and reject unsupported proxied UDP; cross-engine chains
and automatic engine fallback are unavailable. Native engines expose their actual
settings limits. Engine availability depends on Android version and packaged ABI.
Conjure was not verified end-to-end on a public phantom; see the engine specification.
Full Android/device/always-on/lockdown/16 KB-page runtime acceptance remains incomplete.

This beta is separate from the stable update channel. The stable release remains 1.6.10.
